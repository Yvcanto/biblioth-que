    Remarques

    Synchronisation et sauvegarde

    Synchronisation GitHub

    Vos livres sont enregistrés dans un fichier de votre dépôt GitHub privé. Ils sont ainsi les mêmes sur tous vos appareils.

    Le jeton reste uniquement dans ce navigateur. Créez-le avec l'accès au seul dépôt de données, permission « Contents : Read and write ».

    Sauvegarde

    L'export CSV s'ouvre dans Excel, LibreOffice ou Google Sheets. L'export JSON est une copie complète, réimportable ici.

    Cadrez la ligne « ISBN … » dans le rectangle, assez près pour que les chiffres soient nets.

    Placez le code-barres du livre dans le cadre.
